# Dichter_und_Denker - Fluxer Zitat Bot

Ein einfacher Bot für Zitate auf Fluxer.

## Befehle
- `!quote "Zitattext"|Autor` - Erstellt ein Zitat mit heutigem Datum
- `!quote "Zitattext"|Autor|Datum` - Erstellt ein Zitat mit angegebenem Datum

## Beispiele
```
!quote "Carpe Diem"|Seneca
!quote "Ich denke, also bin ich"|Descartes|1637
```

## Bot einladen
Klicke hier um den Bot zu deinem Server hinzuzufügen:
[DEINE_INVITE_URL_HIER_EINFÜGEN]

## Features
- ✅ Zitate formatieren
- ✅ Automatisches Datum (heute)
- ✅ Eigene Nachrichten löschen
- ✅ Fehlerbehandlung

## Benötigte Berechtigungen
- Send Messages
- View Channel
- Read Message History
- Manage Messages (zum Löschen)

## Technologie
- C# mit .NET 10.0
- Fluxer.Net Bibliothek
- Serilog für Logging
